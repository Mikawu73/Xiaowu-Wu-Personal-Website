# Xiaowu Wu — personal portfolio

Responsive English portfolio. Plain HTML, CSS and optional JavaScript. No build step or external dependencies.

## Local preview

From this folder, run:

    python -m http.server 8000 --bind 127.0.0.1 --directory dist

Open http://127.0.0.1:8000, or open dist/index.html directly.

## Editing

- dist/index.html: page content. The #projects section is intentionally empty; replace .project-space with completed case studies when ready.
- dist/styles.css: styles and responsive layouts.
- dist/assets/Xiaowu_Wu_Resume.pdf: original downloadable resume. Replace when updated.

Content is based on the supplied resume. The hero illustration is decorative, not measured data. The original downloadable resume retains its original contact details.
